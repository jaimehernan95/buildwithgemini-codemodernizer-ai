System Architecture Overview

  1. ParserAgent: Reads the repository and builds a semantic map of the AST.
  2. SecurityAuditorAgent: Scans the AST map for critical vulnerabilities.
  3. RefactorAgent: Generates unified git diffs to modernize legacy patterns.
  4. QATesterAgent: Verifies the diffs in an isolated sandbox to ensure no regressions.
